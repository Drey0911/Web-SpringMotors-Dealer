# Football PRO

Este proyecto es una pagina web para la gestion de vehiculos, repuestos, fabricantes,
proveedores y usuarios de un concesionario, como tambien un catalogo que puede ser 
alimentado desde el panel de administracion

## Tecnologias

Este proyecto fue realizado con Java Web usando el framework SpringBoot con el enfoque 
entidades, controlador y repositorios con JPA, Servlet y una BD local H2 con plantillas
en Html Thymeleaf, CSS y Boostrap (Contiene tambien conexion para Neon DB y PostgreSQL)

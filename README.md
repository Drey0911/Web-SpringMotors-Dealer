## Descripción

SpringMotors es una plataforma backend desarrollada con Spring Boot diseñada para la gestión eficiente de un concesionario de vehículos. La aplicación permite a los administradores gestionar el inventario de autos, actualizar especificaciones y precios, y consultar disponibilidad. Cuenta con una arquitectura de datos dual, utilizando H2 como base de datos en memoria para un desarrollo ágil, y Neon DB (PostgreSQL) para un entorno de producción serverless, seguro y escalable.
